# rentonnewcastledispatch.com

Static landing site for the Renton & Newcastle Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py rentonnewcastle` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `rentonnewcastle-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
